Intro

I am a kernel architecture engineer at Apple and a recent Pomona College graduate. I like building across abstraction layers: operating-system infrastructure, secure embedded firmware, processor design, and reinforcement-learning controllers for unusual robots.

That curiosity started early. At seven, I picked up both my first tennis racket and Scratch program; years later it led me to captain Pomona-Pitzer men's tennis and build a programmable computer from 74LS logic on breadboards. This site is an attempt to keep track of what came next.

Projects

ICRA 2026 · Vienna, Austria

Graph-Structured Reinforcement Learning for a Transformable-Wheel Robot

I built a custom MuJoCo/MJX reinforcement-learning environment for step traversal and compared a flat MLP policy with a graph-structured actor-critic. The graph models the robot as one body node and four repeated wheel-module nodes, using message passing to encode the platform's morphology and coordination constraints. In our experiments, that structure helped the controller escape early spinning and heaving failure modes faster.

I co-authored the resulting paper and presented the work at the Xplore workshop at ICRA 2026 in Vienna.

8-Bit Computer

To understand what happens below machine code, I built a fully programmable 8-bit computer based on the SAP-1 architecture - first on breadboards and later as a PCB - using 74LS logic gates.

VLSI Transistor-Level CPU

I designed this 8-bit register at the transistor level, specifying the silicon doping, device geometry, wiring, and transitions between metal layers. It was the next step down the abstraction stack after the breadboard computer.

Read the project log.

NeoObscura Phototransistor Camera

NeoObscura is a custom camera sensor built from 1,200 phototransistors with hardware-accelerated image compression. A 32-bit Arm Cortex-M4 MCU and iCE40 FPGA work together to produce a 40-by-30-pixel image.

Visit the project site.

FPGA-Based AES-128 Hardware Accelerator

Open the project report

This SystemVerilog AES-128 accelerator uses a sequential architecture to fit within roughly 5,000 FPGA LUTs. It receives plaintext and a key from an MCU over SPI, then returns the ciphertext and a ready signal.
